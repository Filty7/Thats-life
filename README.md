# To je život

Klidná hra o životě v reálném čase. Jeden rok trvá minutu a půl. Příležitosti přicházejí a odcházejí. Některé chytíš, jiné necháš plout. Čemu dáš svůj čas, to se z tebe stane.

## Jak spustit

Hra je jeden soubor `index.html` bez závislostí. Stačí ho otevřít v prohlížeči, nebo zapnout GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

Na mobilu se hraje na šířku.

## Co ve hře je

- Karty příležitostí v osmi tématech (práce, vzdělání, rodina, přátelé, koníčky, sport, cestování, zdraví), které se přetahují na osu dne 6:00–6:00.
- Odpočinek, energie, zdraví a stres, které se mění podle toho, jak si den poskládáš. Překrývání karet se nevyplácí.
- Dovednosti 0–10 a motivace, které se během života mění (a vždycky je něco, co tě štve).
- Peníze, bydlení, půjčky, hypotéka, investice, podnikání, pojištění, auto.
- Partner, svatba, děti se vztahy a vlastním směrem, vnoučata.
- Pixelová krajina (vesnice, venkov, město, velkoměsto) s ročními obdobími a střídáním dne a noci, generovaná hudba a zvuky.
- Na konci krátký příběh tvého života a graf, jak rostly dovednosti.
